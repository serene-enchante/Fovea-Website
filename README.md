# Fovea

The _fovea centralis_ is the part of bird's eyes which allow them to see distance objects with acute detail. Likewise, this project provides a centralized and concise environment to view and iterate broad, de-centrlaized citizen science data. The web interface abstracts professional data schemas and organizion practices so that contributers can maintain autonomy other their data input while still enforcing scientific data validity.

## Checks

Run the data and module-contract tests with:

```sh
npm test
```

Run browser checks in installed Google Chrome with:

```sh
npm run test:browser
```

The browser suite covers map deep links, circle selection and return navigation, GeoJSON download, and mobile navigation.
